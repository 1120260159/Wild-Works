本次作业里，Agent 首先帮我通读了课程大纲，把零散要求拆成“环境截图、命令练习、Agent 过程、README”四块，并给出可直接在 Ubuntu 上复现的实验脚本。遇到的第一个问题是本机沙箱禁止启动 WSL，无法在这里直接拿到 Ubuntu 22.04 的真实输出；第二个问题是渲染依赖 Pillow 在当前环境装不上。解决办法是：不伪造任何数据，改为把“执行命令”和“生成截图”分离——capture.sh 在真实 Ubuntu 上采集输出，make_screenshots.py 再把它画成终端截图，Agent 自己的分析步骤也用同一套方式如实呈现。我的收获是：Agent 擅长规划与组织，但真实环境与最终结果仍需本人核对；可复现的实验脚本比一次性截图更有价值，也更符合课程强调的“不把推测写成结果”。
